# Agent của HiTechCloud SDK

Các cấu hình AI agent để sử dụng HiTechCloud SDK.

## Các agent sẵn có

- [service-manager](service-manager.vi.md) — Quản lý dịch vụ HiTechCloud
- [billing-agent](billing-agent.vi.md) — Xử lý thanh toán và hóa đơn
- [dns-agent](dns-agent.vi.md) — Quản lý vùng DNS và bản ghi
- [domain-agent](domain-agent.vi.md) — Đăng ký và quản lý miền

## Cách sử dụng

Các cấu hình agent này có thể được dùng với:
- OpenAI Assistants API
- Anthropic Claude
- Bất kỳ LLM nào hỗ trợ tool use
